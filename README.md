# 🕵️‍♂️ Detective Paw: Flight Mode AR Adventure 🐾✈️

**100% Offline Augmented Reality (AR) educational detective game for kids, specially designed for airplane journeys!**

Designed so children can have fun without getting bored and learn at the same time on a plane, in a car, or anywhere without internet! Detective Paw invites little explorers to solve the mysteries of world-famous historical landmarks.

## 🚀 Quick Start: Download and Play the Game (Android)

Follow the steps below to try the game right away!

1.  **Download the APK File:**
    *   Download the game's `.apk` installation file to your phone by clicking the link below.

      **[➡️ Download Detective Paw v1.0 APK](https://github.com/Adil-Can-Kural/DetactiveAR/releases/download/DPTKV1.0/DPTKv1.0.apk)**
      *(699 MB)*

2.  **Allow "Unknown Sources":**
    *   Android requires additional permission to install apps downloaded outside the Google Play Store.
    *   If a warning appears when you try to open the downloaded file, tap the "Settings" button and enable the "Allow from this source" option.
    *   You only need to do this once.

3.  **Install the Game:**
    *   After granting permission, go back and tap the "Install" button.
    *   Once the installation is complete, you can start the adventure by tapping the "Open" button!

## ✨ Key Features

*   📶 **100% Offline Operation:** Uninterrupted gaming experience in airplane mode or environments without internet.
*   ✈️ **Travel-Friendly:** Specially designed for airplane journeys; ideal for playing on small surfaces like an airplane tray table.
*   🗿 **Famous Historical Landmarks:** Explore iconic structures like Big Ben, the Eiffel Tower, and their surroundings in 3D AR.
*   👇 **Easy Virtual Navigation:** No need to physically move around! Navigate around the model using simple on-screen virtual controls (joystick/arrows).
*   🔍 **Hidden Clues & Discovery:** Find missing pieces on historical landmarks with the guidance of cute Detective Paw.
*   🧠 **Edutainment (Learning While Having Fun):** Learn age-appropriate, interesting facts about historical places after each discovered piece.
*   🎨 **Kid-Friendly Design:** Simple interface, vibrant visuals, and a cute character appealing to the 6-9 age group.
*   🐶 **Cute Guide:** Detective Paw accompanies and guides children throughout the game.

## 🎯 Target Audience

*   Children aged 6-9.
*   Parents looking for an educational and quality screen-time activity for their children while traveling (especially by plane).

## 💻 Tech Stack

*   **Game Engine:** Unity 
*   **Programming Language:** C#
*   **AR Platform:** AR Foundation (covers ARKit for iOS, ARCore for Android)
*   **UI:** Unity UI (with TextMeshPro)
*   **Local Data:** PlayerPrefs - For user progress and settings.
